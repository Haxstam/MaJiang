# 正方形牌桌与UI绑定

更新：2026-11-20。跨对话开发先读 [UI交接文档](UI_HANDOFF_2026-11-20.md)。以作者重新排版的 `MaJiangUnity/Assets/Scenes/TableDebug.unity` 为当前对局界面。CanvasScaler参考尺寸1080×1080，保留作者牌桌区域、四席位置与旋转。`TableDebug 1.unity` 备份场景、旧TablePreview和Table Canvas的布局未迁移为新设计。

## 已确认的交互

- 单击合法舍牌后显示该选择的听牌预估。未选舍牌时，已经听牌可悬停「!」查看当前等待。单独的「振听提示」显示当前座位的实际振听状态，列表里的振听标记按预估舍牌后的等待重算，并保留仍有效的见逃振听。
- 预估按普通荣和计入确定役种及表宝牌。选中合法的立直宣言牌时计入立直或两立直。余量合并赤五与普通五，统计本人手牌、摸牌和公开牌，已鸣走的牌在牌河和副露中只扣一次。
- 点击立直后，合法宣言牌保持明亮，其余手牌和摸牌用 Card 的 BlackMask 压暗并禁止点击。再次点击立直可退出选牌。
- 手中、牌河和副露的可见表宝牌与赤宝牌有斜向循环扫光。缩放和方向随牌体旋转。暗牌、宝牌指示牌和结算牌不扫光。
- 舍牌响应阶段，仅当次舍牌有半透明金框。当前控制席可吃、碰、明杠或荣和时，再叠加一个缩放、呼吸的金框。提交本席响应后，基础金框随响应阶段结束清除。

在牌桌画布 Prefab 的 `MahjongTableView` 调整 `Dora Sweep` 和 `Discard Frame`。扫光可调颜色及透明度、扫过时长、停顿、宽度、方向、内缩和不同牌面的错开时间。金框可调颜色、边距、呼吸周期、透明度区间和缩放区间。缩放初始为 0.9–1.1 倍。金框 Sprite 由 `MahjongTileArt` 引用《圆角矩形框.psd》。

- 手牌条整体长度固定。暗手从左起排，副露靠右向左延伸，副露增多时暗手减少。摸牌跟随暗手最右边，间隔10个局部UI单位；整条场景缩放后间隔同步缩放。
- 暗手自动排序，点击仍对应原始手牌身份。副露继续使用Left/Top/RightClaimGroup，组间隔0，普通牌底边与暗手齐平，上层杠牌可以向上外溢。
- 门清通常为13张暗手；轮到自己摸牌后为13张暗手加1张独立摸牌。有副露时暗手相应减少。SingleTile只放入独立“摸牌”Card，不参与暗手排序；手切后将保留的摸牌并入暗手，摸切直接移除独立摸牌。吃碰后没有摸牌时隐藏独立Card。
- 没有摸切操作按钮。沿用单击选中、再次点击确认：点击独立摸牌提交TakeCut，点击暗手提交HandCut；立直选择则提交Riichi。跳过按钮只在响应窗口出现，不能代替舍牌。
- 若较多副露和横牌使牌条超宽，暗手、摸牌和副露统一等比缩小以避免重叠，10单位摸牌间隔保留。各条的长度不变。
- 操作只有一种具体组合时直接执行；多种组合时打开鸣牌选择面板。取消只关闭选择面板，不提交跳过。
- 吃／碰选择显示实际使用的两张手牌。234506筒吃4筒有23、35、30、56、06五种，普通五与赤五不会合并。暗杠／加杠显示“杠”加一张目标牌，隐藏另一张牌，组宽不变。
- 供托显示点数：一根立直棒显示 `供托+1000`，没有时显示 `供托+0`。桌心四席点数显示各自当前分数。

## 场景字段对应

MahjongTableView的四席数组依次为自家、下家、对家、上家。四座调试固定以绝对0号座位为下方视角。下方暗手和摸牌随控制席切换，自家副露在查看自家时显示。正式单客户端仍按自身座位映射。

| 视图字段 | 场景对象／数据 |
| --- | --- |
| HandStrips、Hands、Melds | 四个手牌区Prefab实例及其内部暗手、副露区域；摸牌使用Prefab自带Card |
| Rivers | 四席牌河；继续使用六列、左上角起排、无缝紧密牌河布局 |
| Players.Name | 四个玩家信息区的名称；等级与评级暂保留作者静态展示 |
| Players.Points、Players.Wind | 桌心各家点数、各家风位 |
| Players.Riichi | 对应座位的立直棒对象 |
| Round、Counters、Remaining | 桌心局目、本场数、剩余牌数 |
| Deposits | 顶部供托文字，立直棒数量×1000 |
| Indicators | 顶部宝牌指示牌列表，左向右共五格，未翻开时牌背 |
| Actions、ActionLabels | 立直、吃、碰、杠、和牌、跳过、九种九牌；无合法动作时隐藏对应按钮，不提供摸切按钮 |
| ChoicePanel | 鸣牌选择面板、排序列表、取消按钮和鸣牌选择组Prefab |
| RoomButton | 顶部调试按钮，展开／收起四座调试面板 |

新设计没有旧版计时器、操作提示条、连接状态条、重开按钮及回合描边。对应字段允许为空；调试信息、推进时间和重开整场仍在F1调试面板中。旧结算内容放入独立“结算内容”容器，并在方形遮罩内居中。

座位按逆时针递增，画面自家在下、下家在右、对家在上、上家在左。风位从本局庄家起依次东南西北；自家是东时右侧南、上方西、左侧北。四席数组和风位通过MahjongSeatOrder统一映射，结算／房间概览也按当前庄家显示风位。调试模式默认跟随待操作座位，下方调试文字显示当前查看的座位、风位和姓名。F1面板仍显示手牌数据并允许手动切换。

按钮列表从右起排、间隔10；选择组间隔10，面板宽度为列表实际宽度加外框留白。可通过MahjongChoicePanel的GroupSpacing和HorizontalPadding调整选择面板。不要给按钮／选择组开启强制扩展宽度，否则固定间隔会被额外空白放大。

## 2026-11-20：显示交互补充

- 宝牌列表直接生成五个Card，不使用牌布局单元；未翻开的格子显示正常牌背。
- 鸣牌选择框关闭按钮采用右上角锚点与右上角轴心，向内留6单位边距，随外框变宽／变窄。列表留白仍为HorizontalPadding。
- BlueMask只用于悬停同牌提示，选中抬牌不再点亮它。悬停当前显示的暗手或摸牌时，仅牌河与副露中的可见同花色／同点数牌亮蓝色；赤五与普通五一起匹配。所有手牌（含悬停牌本身和摸牌）、牌背、暗杠外侧暗牌、宝牌指示牌、选择框牌与结算牌均排除；移出、提交操作、切换手牌和禁用视图时清除。
- 四个当前玩家指示绑定TurnLights，保留作者灯色，2秒周期在25%至100%透明度间呼吸。刚摸牌、等待舍牌、鸣牌后舍牌及抢杠窗口保持当前行动者的灯；舍牌响应期间原行动者继续亮，裁定后转移到鸣牌者／下一位摸牌者；流局／和牌后全灭。
- DebugHandLabel绑定作者的“调试文字”；FixedTableSeat由调试控制器设为0，控制席仍按真实SelfSeat提交命令。
- 检查发现Unity会把布局驱动的摸牌Rect尺寸及缩放保存为0。MahjongHandStripLayout新增TileWidth（默认40），独立保存正常牌宽；不再用被驱动的Drawn.sizeDelta.x推导摸牌宽度，运行时按实际席位牌宽更新该字段。

新增核心检查覆盖仅牌河／副露可用的蓝色滤镜匹配与排除、真实舍牌响应／下家摸牌灯转移、各阶段灭灯及固定公共座次；资源检查覆盖直接宝牌子节点、关闭按钮锚点、四灯和下方调试文字引用。未进行Unity Play和视觉验收。改动前局部备份位于`.utmp/baselines/2026-11-20-before-table-interactions/`。
